# 📋 New Operator Checklist

Use this checklist to go from zero to a running CSM Node Operator. Each step links to the page that covers it.

## Get familiar with CSM

- [ ] Read the [Community Staking Module page](https://operatorportal.lido.fi/modules/community-staking-module) on the Node Operator Portal, including what Lido expects from Node Operators.
- [ ] Choose a module, 0x01 CSM or 0x02 CSM, and an operator type. See [Context & Background](/run-on-lido/csm/context-and-background).

## Apply for an operator type (optional, 0x01 CSM only)

- [ ] [Apply for ICS](https://csm.lido.fi/type/ics-apply), or have your cluster [apply for IDVTC](https://csm.lido.fi/type/idvtc-apply). See [Applying for ICS and IDVTC](/run-on-lido/csm/lido-csm-widget/applying-for-ics-and-idvtc).

## Join the community (optional)

- [ ] Join the [Lido Discord server](https://discord.com/invite/lido).
- [ ] Claim the "CSM Operator" and "community-staker" roles in [this channel](https://discord.com/channels/761182643269795850/1255114639168245790/1256158700284936234).

## Prepare your setup

- [ ] Test your setup on Hoodi with the [CSM Widget for Hoodi](https://csm.testnet.fi/).
- [ ] Set up your node. See [Node Setup](/run-on-lido/csm/node-setup/).
- [ ] Generate validator keys with the credential type of your module. See [Generating Validator Keys](/run-on-lido/csm/generating-validator-keys/).
- [ ] Set the [fee recipient](/run-on-lido/csm/troubleshooting/setting-the-fee-recipient-for-csm-validators) and set up [MEV-Boost](/run-on-lido/csm/node-setup/mev-boost) with relays from the vetted list.
- [ ] Create your Node Operator, upload your keys, and provide the bond in the CSM Widget ([Mainnet](https://csm.lido.fi/), [Hoodi](https://csm.testnet.fi/)). See [Upload, remove, and view validator keys](/run-on-lido/csm/lido-csm-widget/upload-remove-view-validator-keys).
- [ ] Use a hot wallet as the Manager Address and a cold wallet or multisig as the Rewards Address. See [Operator Roles](/run-on-lido/csm/lido-csm-widget/operator-roles).

## Subscribe to alerts (optional, strongly recommended)

- [ ] Share your contact details with your Operator ID ([Mainnet](https://tally.so/r/nGJWgo), [testnet](https://forms.gle/8AVyeCLorTtrxaXo9)).
- [ ] Subscribe to events through the CSM Sentinel bot for 0x01 CSM ([Mainnet](https://t.me/CSMSentinel_bot), [Hoodi](https://t.me/CSMSentinelHoodi_bot)) or 0x02 CSM ([Mainnet](https://t.me/CSM0x02Sentinel_bot), [Hoodi](https://t.me/CSM0x02SentinelHoodi_bot)), or set up [custom alerts](/run-on-lido/csm/alerts-and-monitoring/expert-custom-alerts).
